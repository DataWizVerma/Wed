## 🎵 Music Player Kaise Kaam Karta Hai?

Website mein **Dual-Engine Music Player** lagaya gaya hai:

1. **Instant Wedding Melody (Default):**
   - Jab mehmaan **"Tap the seal to open"** par click karte hain, to pure Web Audio API se sweet romantic acoustic harp & strings dhun turant play hone lagti hai!
   - Isme kisi internet buffering, YouTube block ya ads ki zaroorat nahi hoti. Ye sabhi phones (Android, iPhone Safari, Chrome, Laptop) par 100% chalegi!

2. **Apna Bollywood Song (e.g. Kesariya.mp3) Lagane Ka Tareeka:**
   - Agar aapko apna downloaded MP3 gaana bajana hai, to bas us gaane ko rename karke `song.mp3` naam se `wedding-website/music/` folder mein daal dein:
     ```
     wedding-website/music/song.mp3
     ```
   - Website automatically pehle aapka MP3 gaana bajayegi! Agar MP3 na mile to automatic soothing wedding harp melody bajegi.
